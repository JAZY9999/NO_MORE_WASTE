Execution automatique
Rappels automatiques
Quand c'est desactive, plus aucun email n'est envoye automatiquement. Le declenchement manuel reste possible.
Envoyer a 8 h un jour ouvre plutot qu'a 3 h du matin un dimanche augmente les chances que le message soit lu. C'est aussi plus facile a verifier : on voit passer les envois pendant les heures de bureau.
